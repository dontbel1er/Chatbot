Чат-бот с возможностью сложения чисел и диалоговой логикой

Фунционал:
Распознавание команд, указанных ранее в ТЗ;
Умение работать с мат.операторами;

Команды: 
/start - начать

/name: - указать имя

/number: "","" - указать номер

+ / - / * / / - указать оператор. Действия возможны только в указанном порядке.

Запуск: Скачать архив;
Запустить HTML файл.
